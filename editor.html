GitHub connection

The editor saves to data/sites.js in your repo. It needs a GitHub fine-grained token with Contents: Read and write on this one repo only. The token stays in this browser on this computer.

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Dive-Moore-Site-Guide.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Copy the token and paste it below.
